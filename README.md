## Description 
> CleanSweep is web platform that connects households and property owners with cleaners based on their constraints and preferences. Trying to find a reliable selection of trusted cleaners can be a struggle for those with specific living spaces, locations, and budgets. CleanSweep provides a simple way of searching and discovering cleaners, cleaning services, pricing, locations, and booking appointments on a user friendly interface.
